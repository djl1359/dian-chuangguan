# 电闯关·电工大作战 V1.5.2.0 升级报告

升级基准：V1.5.1.0
发布形态：双版（JSON 数据库版 + Access 数据库版）服务端 exe + 完整源码 + 安装包 zip
端口：双版统一 8123（测试副本 8124/8125 已错开验证后停止）

## 一、本次升级内容：电路图能力（3 大项）

### ① 题库/试卷题目按题干自动生成电路图（本地规则引擎）
- 新增 public/js/circuit.js 本地电路图引擎（不联网、离线可用）
- 「✨ 按题干自动生成」：根据题干正则提取 R1/R2/E/V 等元件参数与 串联/并联/混联 拓扑，自动布图
- 识别示例：题干含「R1=10Ω，R2=20Ω，电源 E=12V」→ 自动生成含 10Ω/20Ω 电阻 + 12V 电源的串联电路
- 题库管理新增电路图区块四按钮：🧾 编辑电路图 / ✨ 按题干自动生成 / ⚡ 自动解答填入 / 🗑 移除电路图
- 电路图显示大小可选 40/60/80/100%；保存字段 circuit + circuitSize；列表行 🔌 标记带图题
- 渲染接入：闯关答题题干、标准试卷预览/导出、在线答题预览、Word/WPS 导出、PDF 导出统一渲染

### ② 手动电路图编辑器（元件库更全，27 种）
- 按 7 组分类：电源（电池/直流/交流/恒流源）、电阻（电阻/滑动变阻器/电位器）、开关保护（开关/熔断器/断路器/按钮）、储能（电容/电感）、半导体（二极管/LED/三极管NPN/PNP）、电机电器（电动机M/发电机G/变压器/继电器/接触器）、仪表（电流表A/电压表V/欧姆表Ω/灯泡/接地/节点）
- 编辑器能力：拖拽放置、移动、连线（导线自动吸附）、旋转、删除、双击修改参数、撤销/重做、清空、导入/导出 SVG、手机端触摸操作
- SVG 白名单消毒（cleanSvg）防 XSS 注入

### ③ 电路图 + 题干自动生成解答（中文已知/求/解/答）并自动填入表单
- 「⚡ 自动解答填入」：根据题干中参数自动计算并填入「答案」输入框与「解析」文本域
- 示例：R1=10Ω、R2=20Ω、E=12V 串联 → 答案 0.4，解析完整输出
  【已知】U=12V，R₁=10Ω，R₂=20Ω（串联）【求】电路电流 I、R₁ 两端电压 U₁【解】R总=R₁+R₂=30Ω，I=U/R总=12/30=0.4A，U₁=I×R₁=4V，U₂=I×R₂=8V，P=U×I=4.8W【答】电流 0.4A，U₁=4V，U₂=8V，总功率 4.8W

### 其他同步与修复
- Access 版全部同步：questions 表新增 circuit/circuitSize 字段（自动迁移）、前端 6 文件同步、服务端 8 处同步点
- Access 写稳定性修复：worker 超时 30s + taskkill 进程树清理 + 自动重试 3 次；写链失败重置，避免一次失败永久阻塞后续写入
- 服务端校验 validateQuestion 支持 circuit/circuitSize；公开考试接口透传电路图
- 双版数据清理：仅保留教师账号（users=1）+ 题库（questions=2649），其余表清空
