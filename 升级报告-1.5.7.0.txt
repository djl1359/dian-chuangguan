二、本次升级内容（电路图编辑器三项功能）
  1. 纵向滚动条
     - public/css/style.css：.circ-canvas-box 固定高度
       height:60vh; min-height:320px; max-height:640px; overflow-y:auto
       + Webkit 滚动条视觉样式
     - 编辑区内容过长时可纵向滚动，提示条固定在容器外不随滚动消失
  2. Shift 锁定（水平/竖直移动或延伸）
     - public/js/circuit.js _onMove：拖动元件时按住 Shift，按位移较大
       方向锁定单轴（水平或竖直），并 10px 网格吸附
     - 导线折弯拐点拖动同样支持 Shift 单轴锁定
  3. 电压标注（+ − 两端点 + 中间电压）
     - public/js/circuit.js 新增 volt 模式：
       · 工具栏「⚡ 电压标注」按钮
       · 依次点击两个端点生成橙色引线 + 三角箭头 + 端点“+”“−”+
         中间电压文字（默认 VAB）
       · 双击符号切换 +/−；双击电压文字输入电压值（如 UAB=10V）
       · 撤销/重做/清除/导出/导入均包含电压标注
       · 导出 SVG 携带 data-v/data-va/data-vb/data-vs/data-vt 属性，
         落库后渲染端（闯关/试卷/答题卡）一致显示
  4. 版本号：双版 server.js VERSION='1.5.7.0'，启动时自动写入数据库
     settings.version；登录页/版权行显示（1.5.7.0 JSON数据库版 /
     Access数据库版）

五、安装/使用说明
  1. Windows 电脑：解压对应版本安装包 → 双击“启动服务-XXX版.bat”
     （推荐，需电脑安装 Node.js）或“电闯关服务端-JSON版.exe”
     （JSON 版 exe 已验证可用）启动服务 → 浏览器访问
     http://127.0.0.1:8123
  2. 【Access版特别说明】Access 版 pkg exe 在部分 Windows 环境存在
     历史问题（进程存活但无法监听端口，V1.5.6.0 起已存在，已实测确认），
     请使用“启动服务-Access版.bat”源码方式启动（功能完全正常，
     全部功能已实测通过）。
  3. 局域网/手机：查看服务端启动窗口显示的局域网 IP 与端口，
     手机浏览器访问 http://<电脑IP>:8123 即可（需同一网络）
  4. 教师默认账号：teacher / 123456（首次登录后可在“账号设置”修改）

六、注意事项
  - Access 版写入较慢（数秒），保存时请等待遮罩提示结束，勿强制关闭。
  - 升级安装前请备份原 data 目录（防止覆盖既有成绩/学生数据）。
  - 使用 .bat 源码启动需电脑已安装 Node.js；无 Node.js 的电脑建议使用
    JSON 版 exe（自包含，无需安装 Node）。
