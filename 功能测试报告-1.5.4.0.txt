【测试方法】

填写题干（串联电路计算题）→ 自动生成电路图 → 点击电路图预览 →
在 lightbox 中通过脚本派发真实 WheelEvent/MouseEvent 验证缩放与拖动。

【测试项与结果】
1. 放大预览打开
   点电路图预览 → 全屏 lightbox 弹出，提示“🖱 滚轮缩放 · 拖动查看 · 点击空白处关闭” ✅
2. 滚轮放大
   派发 wheel deltaY=-240 → transform 变为 scale(1.12)，且以鼠标位置为中心偏移 ✅
3. 连续放大上限
   连续 20 次放大 → scale 收敛于 8.0（上限） ✅
4. 连续缩小下限
   连续 30 次缩小 → scale 收敛于 0.5（下限） ✅
5. 拖动平移
   在电路图 SVG 内部元素 mousedown → mousemove(两次) → mouseup：
   translate 按鼠标位移精确累加（400,300→520,360→560,390 逐点核对正确） ✅
6. 点击空白关闭
   点击 lightbox 空白区 → 遮罩移除（DOM 计数归 0） ✅
7. 版本与缓存
   首页含 VERSION 1.5.4.0；ui.js 引用带 t=3 新缓存参数 ✅
8. 图片（IMG）路径
   同一 zoomView 对 IMG 走 object-fit:contain 分支，缩放/拖动逻辑共用（代码路径相同） ✅
9. Access 版同步
   public/js/ui.js 与 index.html 与 JSON 版逐字节一致；server.js VERSION 1.5.4.0 ✅

【结论】
- 放大预览（lightbox）滚轮缩放 + 拖动查看功能正常，缩放范围 0.5~8 倍，
  鼠标位置缩放精确、拖动跟手、点击空白关闭无残留。
- JSON 版浏览器实测全部通过；Access 版前端与 JSON 版同一份代码（Copy-Item 同步），
  冷启动验证正常。
- 测试过程未产生业务数据（未保存测试题目），题库保持 2649 题。

【遗留说明】
- Access 版冷启动 3~5 分钟、写操作 20~30 秒带“正在写入请勿关闭”遮罩，属既有机制。
- 触摸设备（安卓手机浏览器）无鼠标滚轮，可改用双指捏合缩放（浏览器原生行为）；
  如需触屏专用缩放按钮可后续迭代。
