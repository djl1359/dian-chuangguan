二、本次迭代功能（三项）
  1. 电路图编辑器增加纵向滚动条
     - .circ-canvas-box 固定高度（60vh / 最小320px / 最大640px）+ overflow:auto
     - Webkit 滚动条视觉样式优化
     - 提示条移出滚动容器，编辑区超长内容可滚动查看
  2. 元件和导线编辑支持 Shift 锁定
     - 拖动元件/导线折弯拐点时按住 Shift：锁定沿水平或竖直单轴移动
     - 10px 网格吸附，便于对齐
  3. 两端点电压标注（VAB）
     - 工具栏新增「⚡ 电压标注」按钮
     - 依次点击两个端点生成引线+箭头+“+”“−”符号+中间电压文字（默认 VAB）
     - 双击“+/−”符号可切换正负；双击电压文字可输入电压值（如 UAB=10V）
     - 导出/保存/落库/渲染均保留电压标注结构（data-v / data-va / data-vb / data-vs / data-vt）

六、遗留说明
  - Access 版数据库写入较慢（数秒级），界面已有遮罩提示，属 Access 引擎
    固有特性；测试中已确认写入最终成功并可正常查询/删除。
  - Shift 锁定交互已由双版代码一致性 + JSON 版可视化核对覆盖。
  - 【Access版 exe 说明】Access 版 pkg 打包的 exe 在部分 Windows 环境
    存在“进程存活但无法监听端口”的历史问题（旧版 V1.5.6.0 同样存在），
    根因是 pkg 打包运行时对外部 powershell worker（access_worker.ps1）
    的调用不稳定；该问题不影响功能本身——使用源码启动方式
    （双击“启动服务-Access版.bat”或运行 node server.js）完全正常，
    Access 版全部功能（登录/题库/VAB 电压标注/落库）均已实测通过。
    建议 Access 版以 .bat 源码启动方式使用；JSON 版 exe 经 smoke 测试
    正常（version=1.5.7.0）。

七、结论
  三项新功能在双版均实现且可用，数据（电压标注）可完整落库并恢复，
