《电闯关·电工大作战》V1.5.3.0 功能测试报告
========================================

测试日期：2026-10-12
测试环境：Windows 本机（JSON 版端口 8123 / Access 版端口 8125）

一、测试范围
本次针对三项新功能进行双版同步实测：
① 电路图国标符号（GB/T4728）
② 题目编辑点击放大预览
③ 题目可选是否展示图片/电路图

二、测试用例与结果

【JSON 版（端口 8123）】

用例 1：新增题目弹窗含「答题时展示题干图片与电路图」复选框
  步骤：教师登录 → 题库管理 → 新增题目
  预期：弹窗出现 showImg 复选框且默认勾选
  结果：通过（checkbox id=qf-showimg 默认 checked）

用例 2：按题干自动生成电路图 + 预览可点击放大
  步骤：题干填写串联电路计算题 → 点「✨按题干自动生成」→ 点电路图预览
  预期：生成 10Ω/20Ω/12V 串联电路图；预览容器含 cursor:zoom-in 与 onclick=UIM.zoomView
  结果：通过（S.qfCircuit 生成 2286 字符；预览容器 onclick 已挂载）

用例 3：放大预览 lightbox 弹出/关闭
  步骤：点击电路图预览 → 查看全屏 lightbox → 点击关闭
  预期：全屏遮罩（z-index 99999）放大显示 SVG，点击任意处关闭
  结果：通过（LIGHTBOX svg=true cap=true，关闭正常）

用例 4：showImg=false 保存与列表透传
  步骤：取消勾选 showImg → 保存 → 查询列表接口
  预期：题目保存成功；列表接口返回 showImg:false
  结果：通过（POST /api/questions/admin 返回 ok id 2651；列表接口 showImg:false）
  清理：测试题 2651 已删除

用例 5：版本号显示
  预期：首页/登录页显示 V1.5.3.0
  结果：通过

【Access 版（端口 8125）】

用例 6：冷启动与版本
  步骤：启动 Access 服务 → 访问首页
  预期：服务正常监听，首页含 1.5.3.0
  结果：通过（冷启动约 5 分钟属正常）

用例 7：登录与题库列表 showImg 透传
  步骤：POST /api/login（teacher/123456）→ GET 题库列表
  预期：登录返回 token；列表题目含 showImg:true（旧库迁移默认）
  结果：通过（showImg 列自动迁移成功）

用例 8：Access 版新增 showImg=false 题目
  步骤：POST 新增（showImg:false）→ 删除
  预期：新增成功（id 2650），删除成功
  结果：通过

用例 9：国标符号源码核对（双版）
  检查 circuit.js DEFS：
  - dc 直流电源：长线+短线，+/− 标注 ✓
  - sw 开关：右端动触头折线抬升（国标常开画法）✓
  - zd 稳压管：折线沿二极管方向右下转折 ✓
  结果：通过

三、遗留说明
- Access 版冷启动约 3~5 分钟（Access 数据库 worker 初始化），写操作约 20~30 秒有「正在写入请勿关闭」遮罩，属既有机制
- 弹窗内多次 JS 注入操作时表单事件绑定可能受干扰，正常人工操作不受影响（已用直连接口复验保存链路）

四、结论
三项新功能在 JSON 版与 Access 版均实现并实测通过，测试数据已清理，可发布。
