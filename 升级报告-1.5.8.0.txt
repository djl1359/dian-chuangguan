==========================================================
《电闯关·电工大作战》升级报告  V1.5.8.0
==========================================================
升级日期：2026-10-13
升级版本：V1.5.7.0 → V1.5.8.0

----------------------------------------------------------
一、升级内容
----------------------------------------------------------
1. 电路图编辑器元件库按国家标准（GB/T 4728 图形符号、
   GB/T 7159 文字代号、GB/T 6988 画法）全面核对修正：
   - 灯泡：L → EL
   - 二极管：D → VD
   - LED：D → VL
   - 稳压管：D → VS
   - 熔断器：图形加矩形内斜线（国标符号）
   - 蜂鸣器：补文字代号 HA
2. 前端缓存参数 t=7 → t=8，确保升级后浏览器加载新版元件库
3. 版本号升级并写入数据库 settings.version=1.5.8.0

----------------------------------------------------------
二、升级文件
----------------------------------------------------------
JSON数据库版：
  public/js/circuit.js   （元件库国标修正）
  public/index.html      （缓存参数 t=8）
  server.js              （VERSION=1.5.8.0）
Access数据库版：
  public/js/circuit.js   （与 JSON 版逐字节一致）
  public/index.html      （与 JSON 版逐字节一致）
  server.js              （VERSION=1.5.8.0）

----------------------------------------------------------
三、升级方式
----------------------------------------------------------
方式一：替换服务端目录中上述文件，重启服务（node server.js）
方式二：使用完整安装包（电闯关-完整版-*.zip）全新部署
  JSON版：  启动服务-JSON版.bat → http://localhost:8123
  Access版：启动服务-Access版.bat → http://localhost:8123

----------------------------------------------------------
四、注意事项
----------------------------------------------------------
1. 已有题目中的电路图数据（保存的 SVG）不受本次元件库
   修改影响（旧符号仍按原样渲染），新建电路图使用新代号。
2. Access 版服务端启动若遇 PowerShell worker 不稳定
   （V1.5.6.0 起已知），请使用"启动服务-Access版.bat"以
   node 源码方式启动，并在浏览器访问 http://localhost:8123。
3. 手机/局域网访问：浏览器打开 http://本机IP:8123。
