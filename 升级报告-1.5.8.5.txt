==========================================================
《电闯关·电工大作战》升级报告  V1.5.8.5
==========================================================
升级日期：2026-10-13
升级版本：V1.5.8.4 → V1.5.8.5

----------------------------------------------------------
一、升级内容
----------------------------------------------------------
电路图编辑器元件库国标核查与补充：
1. 逐项核查三项国标符合性：
   - GB/T 4728 电气简图用图形符号（符号画法）
   - GB/T 7159 电气技术中的文字符号制订通则（文字代号）
   - GB/T 6988 电气技术用文件的编制（画法与布局）
2. 修正不符合项：
   - NPN 三极管发射极箭头方向（原指向基极，修正为向外）
   - 电位器补充第三端子（滑动抽头）
3. 补充 15 个教材常用国标元件：
   发电机 G、交流发电机 G~、刀开关 QS、断路器 QF、
   热继电器 FR、行程开关 SQ、时间继电器 KT、
   中间继电器 KA、三相电动机 M3~、电流互感器 TA、
   电压互感器 TV、功率表 PW、可变电容 C、
   光电二极管 VD、电铃 HA
4. 元件库总数：36 → 51 个。
5. 前端缓存参数 circuit.js t=12 → t=13。
6. 版本号升级并写入数据库 settings.version=1.5.8.5。

----------------------------------------------------------
二、升级文件
----------------------------------------------------------
JSON数据库版：
  public/js/circuit.js   （元件库核查修正+15新元件+分组）
  public/index.html      （缓存参数 t=13）
  server.js              （VERSION=1.5.8.5）
Access数据库版：
  public/js/circuit.js   （与 JSON 版逐字节一致）
  public/index.html      （与 JSON 版逐字节一致）
  server.js              （VERSION=1.5.8.5）

----------------------------------------------------------
三、升级方式
----------------------------------------------------------
方式一：替换服务端目录中上述文件，重启服务（node server.js）
方式二：使用完整安装包（电闯关-完整版-*.zip）全新部署
  JSON版：  启动服务-JSON版.bat → http://localhost:8123
  Access版：启动服务-Access版.bat → http://localhost:8123

----------------------------------------------------------
四、注意事项
----------------------------------------------------------
1. 新增元件按国标符号与文字代号绘制；电位器第三端子为
   视觉抽头标注（连线仍以左右两端引脚为准）。
2. 旧题目的电路图数据不受影响（元件 key 未改动，
   仅新增/修正画法）。
3. Access 版服务端启动若遇 PowerShell worker 不稳定
   （V1.5.6.0 起已知），请使用"启动服务-Access版.bat"以
   node 源码方式启动，并在浏览器访问 http://localhost:8123。
4. 手机/局域网访问：浏览器打开 http://本机IP:8123。
