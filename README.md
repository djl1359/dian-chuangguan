# ⚡ 电闯关·电工大作战

《电工技术基础与技能（第4版）》（周绍敏 主编）配套的**动作答题闯关 + 教师管理台**双端系统，供 Windows 电脑与安卓手机使用。

> 版权：河北省滦州市职业技术教育中心 · 空城流水老师利用豆包 AI 制做

## 功能总览

- **闯关玩法**：13 章（第 0~12 章，含"物理量识记"全员开放）52 关卡 + 每章 BOSS 战，答对电击消灭故障怪、答错扣心、超时判错；积分/星星/连击/错题本/排行榜
- **题型**：单选、判断、多选、填空、连线（matching）
- **教师管理台**：学生管理、题库管理（339 题增删改查）、成绩分析（每题/节/章全班正确率 + 对错名单、等次卡片、个人成绩分析）、操作日志、闯关时间设置、账号设置
- **成绩分析**：全班/个人双模式，同学掌握情况汇总（章·节·题），查找/排序/筛选 + 分页（10/20/30/50/100/自定义）
- **语音读题**：朗读题干与选项，读题期间暂停动画与倒计时；顶部 HUD 与答题区人物静音开关双向联动
- **BOSS 战准备**：进入 BOSS 关先暂停，触控按钮可拖拽调整位置，确定后开始
- **自适应布局**：自动检测显示尺寸适配闯关界面（电脑/手机/横竖屏）

## 双版本

本仓库包含两个独立版本（同一套前端，不同数据层）：

| 目录 | 数据层 | 说明 |
|---|---|---|
| `电闯关·电工大作战/` | JSON 文件（`data/db.json`） | 零依赖 Node 服务端，开箱即用 |
| `电闯关·电工大作战-Access版/` | Microsoft Access（`dg_data.accdb`） | 通过 `access.js` + `access_worker.ps1` 读写 |

> 说明：`dg_data.accdb`（Access 数据库文件）约 1.2MB，已纳入本仓库（位于 `电闯关·电工大作战-Access版/data/`）；若本地缺少该文件，首次启动 Access 版服务端会自动初始化数据库结构与种子数据（教师账号 `teacher` / `123456` + 339 题题库）。

## 快速开始

### 服务端（Windows）

```bat
:: JSON 版
电闯关·电工大作战\启动服务.bat

:: Access 版（需本机安装 Microsoft Access 数据库引擎）
电闯关·电工大作战-Access版\启动服务.bat
```

服务端启动后监听 `8123` 端口，控制台显示版本号。

### 客户端（电脑 / 手机）

- 电脑：浏览器访问 `http://本机IP:8123`
- 手机：同一局域网内访问 `http://电脑IP:8123`
- 或使用仓库内 `电闯关-客户端/` 的说明与快捷方式

### 账号

- 教师：`teacher` / `123456`（可在设置中修改；登录后可在设置中修改使用单位，页面标题同步显示）
- 学生：登录页"注册"标签自助注册（忘记密码请联系老师重置）

## 目录结构

```
电闯关·电工大作战/
├─ server.js            # 服务端（JSON 数据层）
├─ store.js             # JSON 存储
├─ data/
│  ├─ db.json           # 用户/进度/成绩/日志
│  └─ questions.json    # 题库（339 题）
└─ public/              # 前端（index.html + css + js）
电闯关·电工大作战-Access版/
├─ server.js            # 服务端（Access 数据层）
├─ access.js            # Access 读写封装（ACE OLEDB）
├─ access_worker.ps1    # Access 工作进程
└─ data/
   ├─ questions.json    # 题库（339 题）
   └─ dg_data.accdb     # Access 数据库（用户/进度/成绩/日志）
```

## 技术说明

- 服务端：Node.js（零第三方依赖），可编译为独立 exe（pkg）
- 前端：原生 HTML/CSS/JS（Canvas 动作游戏 + 单页应用），无构建
- 题库：339 题 = 单选 218 + 判断 80 + 多选 20 + 填空 15 + 连线 6
