《电闯关·电工大作战》升级报告 V1.5.0.0
（JSON数据库版 + Access数据库版 双版同步升级）
发布日期：2026-10-09
================================================================

一、本次升级内容
----------------------------------------------------------------
1. 学生注册信息增加“学校、年级、班级”三个字段
   - 学校默认预填“河北省滦州市职业技术教育中心”，可修改
   - 年级下拉：一年级 / 二年级 / 三年级
   - 班级为文本框（如：机电2301班），注册后可由教师修改
2. 信息统计 / 成绩分析可按 学校、年级、班级 分别统计
   - 学生管理页新增“全部学校 / 全部年级 / 全部班级”筛选下拉 + 重置按钮
   - 成绩分析页新增同款筛选，统计卡片（学生人数 / 平均正确率 / 优优良中差）随筛选变化
   - 章节分析 / 节分析 / 掌握汇总 均支持按 学校·年级·班级 筛选统计
   - 下拉选项由学生数据动态生成（去重后按中文排序），选项随数据自动更新
3. 学生管理表格新增“学校、年级、班级”列
   - 教师可通过“编辑”按钮修改学生 学校/年级/班级，并写入操作日志
   - 日志记录格式：修改学生信息 旧值 → 新值
4. 服务端接口新增 /api/users/edit（教师修改学生三字段，校验教师身份）
5. 注册接口 /api/register 扩展接收 school/grade/class；用户列表接口返回新字段
6. 数据层迁移（Access 版）
   - users 表新增 school/grade/[class] 列（class 为 ACE 保留字，恒带方括号）
   - 旧库启动时自动 ALTER TABLE 补列（ensureUserCols），不影响已有数据
   - 教师账号不参与统计与排序（沿用 V1.4.5.x 行为）

二、涉及文件（双版同步）
----------------------------------------------------------------
服务端：server.js（注册/用户列表/新增编辑接口/成绩分析四接口筛选）
Access数据层：access.js（DDL、ensureUserCols、insertUser/updateUser/loadAll）
前端：public/index.html（注册三字段、学生管理/成绩分析筛选行）
      public/js/api.js（register/editUser/四分析接口筛选参数）
      public/js/ui.js（筛选联动、编辑弹窗、表格列、动态下拉）
题库与考试功能无改动。
