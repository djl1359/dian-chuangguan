==========================================================
《电闯关·电工大作战》升级报告  V1.5.8.1
==========================================================
升级日期：2026-10-13
升级版本：V1.5.8.0 → V1.5.8.1

----------------------------------------------------------
一、升级内容
----------------------------------------------------------
1. 电路图编辑器画布显示大小调整：
   - 编辑区容器由固定高度（60vh，最高 640px）改为自适应
     （height:auto），默认画布 860×500 完整显示，恢复
     无滚动条时代的显示大小
   - 滚动能力保留：将画布调大后仍可滚动查看
2. 前端缓存参数 css t=6 → t=7，确保升级后浏览器加载新版样式
3. 版本号升级并写入数据库 settings.version=1.5.8.1

----------------------------------------------------------
二、升级文件
----------------------------------------------------------
JSON数据库版：
  public/css/style.css   （.circ-canvas-box 高度自适应）
  public/index.html      （缓存参数 t=7）
  server.js              （VERSION=1.5.8.1）
Access数据库版：
  public/css/style.css   （与 JSON 版逐字节一致）
  public/index.html      （与 JSON 版逐字节一致）
  server.js              （VERSION=1.5.8.1）

----------------------------------------------------------
三、升级方式
----------------------------------------------------------
方式一：替换服务端目录中上述文件，重启服务（node server.js）
方式二：使用完整安装包（电闯关-完整版-*.zip）全新部署
  JSON版：  启动服务-JSON版.bat → http://localhost:8123
  Access版：启动服务-Access版.bat → http://localhost:8123

----------------------------------------------------------
四、注意事项
----------------------------------------------------------
1. 画布默认 860×500 完整显示；若将画布调大，编辑区将出现
   滚动条以便查看完整内容。
2. Access 版服务端启动若遇 PowerShell worker 不稳定
   （V1.5.6.0 起已知），请使用"启动服务-Access版.bat"以
   node 源码方式启动，并在浏览器访问 http://localhost:8123。
3. 手机/局域网访问：浏览器打开 http://本机IP:8123。
