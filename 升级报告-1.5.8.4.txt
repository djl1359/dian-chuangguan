==========================================================
《电闯关·电工大作战》升级报告  V1.5.8.4
==========================================================
升级日期：2026-10-13
升级版本：V1.5.8.3 → V1.5.8.4

----------------------------------------------------------
一、升级内容
----------------------------------------------------------
电路图编辑器画布显示方式调整（用户要求"白色部分加滚动条"）：
1. 画布 SVG 由自适应缩小显示（width:100%）改回按画布原尺寸
   显示（width:画布宽px），元件不再缩小、保持原大小。
2. 画布大于显示区域时自动出现横向/纵向滚动条，可滚动查看
   完整画布；画布小于显示区域时完整显示、无滚动条。
3. 保留布局修复：操作提示文字已在画布下方单独一行，画布
   容器占满编辑器剩余宽度（754px，修复前 198px）。
4. 前端缓存参数 circuit.js t=11 → t=12。
5. 版本号升级并写入数据库 settings.version=1.5.8.4。

----------------------------------------------------------
二、升级文件
----------------------------------------------------------
JSON数据库版：
  public/js/circuit.js   （画布固定尺寸显示+滚动条）
  public/index.html      （缓存参数 t=12）
  server.js              （VERSION=1.5.8.4）
Access数据库版：
  public/js/circuit.js   （与 JSON 版逐字节一致）
  public/index.html      （与 JSON 版逐字节一致）
  server.js              （VERSION=1.5.8.4）

----------------------------------------------------------
三、升级方式
----------------------------------------------------------
方式一：替换服务端目录中上述文件，重启服务（node server.js）
方式二：使用完整安装包（电闯关-完整版-*.zip）全新部署
  JSON版：  启动服务-JSON版.bat → http://localhost:8123
  Access版：启动服务-Access版.bat → http://localhost:8123

----------------------------------------------------------
四、注意事项
----------------------------------------------------------
1. 画布默认 860×500；画布放大（📐+）后超出显示区域出现
   滚动条，可滚动查看完整画布；元件始终按原大小显示。
2. Access 版服务端启动若遇 PowerShell worker 不稳定
   （V1.5.6.0 起已知），请使用"启动服务-Access版.bat"以
   node 源码方式启动，并在浏览器访问 http://localhost:8123。
3. 手机/局域网访问：浏览器打开 http://本机IP:8123。
