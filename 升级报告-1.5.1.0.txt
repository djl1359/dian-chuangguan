# 电闯关·电工大作战 V1.5.1.0 升级报告

升级基准：V1.5.0.0
发布形态：双版（JSON 数据库版 + Access 数据库版）服务端 exe + 完整源码 + 安装包 zip
端口：双版统一 8123（JSON 版与 Access 版不能同时占用默认端口，测试副本已错开端口验证）

## 一、本次升级内容（6 项 + 修复）

### ① 题目编辑器富文本工具条（上下标/公式支持）
- 题库「新增/编辑题目」弹窗中，题干、选项、连线左右列、解析均增加富文本工具条
- 支持：上标 x²、下标 x₁、分数、根号 √、希腊字母下拉（Ω μ φ π α β γ δ θ λ ρ σ ω ε Δ Σ Φ Λ）、乘除号 ×÷・、度数 °、μA、∠ ≈ ≠ ≤ ≥ ±、mm² 等电工符号
- 点击后在光标处插入对应 HTML；提供 👁 预览 / ✏️ 源码 切换
- 历史数据自动清洗：Unicode 上下标、<sup>/<sub> 残留、LaTeX 标记统一规范渲染
- 渲染一致性：闯关答题、试卷导出、成绩分析三处共用统一渲染层

### ② 闯关体验
- 读题暂停动画 → 读完恢复动画并倒计时（已有，本轮核实）
- 下一题初始化动画（换题清弹幕不清人物，已有，本轮核实）
- BOSS 战先暂停、控制按钮可拖动调整位置（已有 showBossReady，本轮核实）
- BOSS 战读题期间禁止答题（已有，本轮核实）
- 结算表扬/鼓励文案教师可配置：系统设置新增「优秀表扬/良好鼓励/通关/失败」四档文案（≤60 字），闯关结算按成绩/星级展示对应文案

### ③ Access 版写操作体验
- 教师写操作期间显示全屏遮罩「正在写入数据，请勿关闭窗口…Access 数据库写入较慢」
- 请求超时 120 秒自动提示并可重试
- CSV 批量导入按 100 行/批分批次写入，进度提示

### ④ 成绩分析：薄弱知识点 + 组卷联动
- 成绩分析统计卡新增「📉 薄弱知识点（全班正确率<60%）」按钮：按章节折叠展示薄弱章节/节/题（正确率、题号、题干）
- 「📝 用薄弱题组卷」按钮：一键跳转组卷，预选薄弱章节、正确率模式=weak，生成针对性试卷

### ⑤ 阅卷考试 PDF 导出
- 组卷页新增「📄 导出 PDF（打印版）」按钮：A4 版式新窗口，含试卷标题/考试信息栏（姓名/班级/学号/得分表）、按题型分组（含分值/答题提示）、单选多选选项内联、判断留（ ）、填空留横线、连线两列留连线横线、计算题「已知/求/解/答」四步答题线、可选参考答案/解析、页脚版权，浏览器另存为 PDF
- 导出 Word/WPS 打印按钮逻辑保持不变

### ⑥ Markdown 更友好
- 统一渲染层支持 **加粗**、*斜体*、`代码`、~~删除~~、[链接]()、标题、列表、LaTeX 公式（$…$、$$…$$、\(…\)）、Unicode 上下标
- 导入弹窗增加 Markdown 与公式提示文案

### 修复
- 题库中残留裸 LaTeX（无 $ 包裹的历史数据，如 `2.51\times10^{-3}`、`\frac{1}{2}`、`\mu_r`、`R_1=10 \Omega`）自动识别转换，公式显示恢复正常
- 试卷/答题卡/PDF 导出中答案、解析统一走 mdMath 渲染
