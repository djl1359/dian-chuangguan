《电闯关·电工大作战》V1.5.3.0 升级报告
========================================

一、版本信息
- 版本号：V1.5.3.0
- 版本类型：正式迭代版（JSON数据库版 / Access数据库版 同步）
- 发布目录：E:\测试项目\发布文件-V1.5.3.0\
- 发布日期：2026-10-12

二、本次升级内容（三项功能需求）
1. 电路图符号按国家标准 GB/T4728 修正（双版）
   - 直流电源：改为国标长线（+）短线（−）画法，正负极标注
   - 开关：改为国标常开动断画法（右端动触头折线抬升）
   - 稳压管：改为折线沿二极管方向（右下转折），符合国标稳压管符号
   - 元件库 27 种元件 7 大类，其余符号保持国标画法

2. 题目编辑时可点击放大预览（双版）
   - 新增全局 UIM.zoomView 放大预览（lightbox 全屏遮罩）
   - 新增题目弹窗中：题干图片预览、电路图预览均可点击放大
   - 点击任意处或图外区域关闭，大图支持缩放滚动查看

3. 题目可选择是否展示图片/电路图（双版）
   - 新增题目弹窗新增「答题时展示题干图片与电路图」复选框（默认勾选）
   - 服务端全链路支持 showImg 字段：
     * 校验（validateQuestion）
     * 新增 / 修改（nq / qq）
     * 列表 / 单题 / 考试组卷 / 在线考试 / Word 导出 / 答题卡导出（qimg、qimg2、qimg3、circDivHtml）
   - 学生端闯关、在线考试、标准试卷、答题卡均遵循 showImg 设置
   - Access 数据库 questions 表新增 [showImg] 列（旧库自动迁移补列，默认 1=展示）

三、测试结论
- JSON 版（端口 8123）：登录 → 题库管理 → 新增题目 → 自动生成电路图 → 点击放大预览 → 取消勾选 showImg → 保存 → 列表接口透传 showImg:false 全部通过
- Access 版（端口 8125）：冷启动 → 登录 → 题库列表 showImg:true 透传（列迁移成功）→ 新增 showImg:false 题目 → 删除 全部通过
- 国标符号源码核对通过（dc/sw/zd 三处已修正）
- 双版测试数据已清理（题库恢复 2649 题原状）
