==========================================================
《电闯关·电工大作战》升级报告  V1.5.8.3
==========================================================
升级日期：2026-10-13
升级版本：V1.5.8.2 → V1.5.8.3

----------------------------------------------------------
一、升级内容
----------------------------------------------------------
修复电路图编辑器"白色画布区域太小"问题（根因修复）：
1. 根因：编辑器 flex 布局中，操作提示文字（.circ-tip 长文本）
   与画布在同一行，占用了大部分宽度，把画布容器挤压到仅 198px
   宽，导致白色画布显示极小。
2. 修复A：操作提示文字移出画布行（单独一行），画布容器占满
   编辑器剩余宽度（198px → 754px）。
3. 修复B：画布 SVG 由固定 860px 改为自适应容器宽度
   （width:100%; height:auto; aspect-ratio 860/500），
   保持 860:500 比例完整显示，不再被容器裁切，无横向滚动条。
4. 前端缓存参数 circuit.js t=10 → t=11。
5. 版本号升级并写入数据库 settings.version=1.5.8.3。

----------------------------------------------------------
二、升级文件
----------------------------------------------------------
JSON数据库版：
  public/js/circuit.js   （tip移出画布行 + SVG自适应）
  public/index.html      （缓存参数 t=11）
  server.js              （VERSION=1.5.8.3）
Access数据库版：
  public/js/circuit.js   （与 JSON 版逐字节一致）
  public/index.html      （与 JSON 版逐字节一致）
  server.js              （VERSION=1.5.8.3）

----------------------------------------------------------
三、升级方式
----------------------------------------------------------
方式一：替换服务端目录中上述文件，重启服务（node server.js）
方式二：使用完整安装包（电闯关-完整版-*.zip）全新部署
  JSON版：  启动服务-JSON版.bat → http://localhost:8123
  Access版：启动服务-Access版.bat → http://localhost:8123

----------------------------------------------------------
四、注意事项
----------------------------------------------------------
1. 画布默认 860×500；自适应容器宽度显示，大屏画布更大、
   小屏按比例完整显示，均无横向滚动条。
2. 画布放大（📐+）后超出容器仍会出滚动条以便查看。
3. Access 版服务端启动若遇 PowerShell worker 不稳定
   （V1.5.6.0 起已知），请使用"启动服务-Access版.bat"以
   node 源码方式启动，并在浏览器访问 http://localhost:8123。
4. 手机/局域网访问：浏览器打开 http://本机IP:8123。
